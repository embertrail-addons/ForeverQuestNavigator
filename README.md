# Forever Quest Navigator

Copyright (c) 2026 Embertrail Addons. All rights reserved. See [LICENSE](LICENSE).

Forever Quest Navigator recommends accepted quests using distance, level fit, and known follow-ups. It reads Blizzard quest log and map data and can compare targets across zone borders on the same continent. The separate level order breaks ties by quest ID and ranks quests without a usable level after quests with a known level. Failed and session-disabled quests are ineligible.

The movable tracker shows one active quest and a configurable list of alternatives. The active quest shows its level and all quest objectives with the game's progress text when available. A completed quest in the log is labeled **Ready to turn in** and remains eligible until it is handed in. Each row shows an approximate distance when the map supplies usable coordinates. The active quest also has a direction arrow when the game exposes the character's facing. The tracker refreshes at login and on quest events. Events that arrive within the same 100 ms window share a refresh.

## Client and installation

Version **0.1.59** targets **World of Warcraft: Forever 1.60.1**, interface **16001**. In automatic mode FQN uses German on German clients and English on other clients. Quest names, objectives, and place names are displayed as supplied by WoW or Questie. [Blizzard's Forever launch announcement](https://news.blizzard.com/en-us/article/24315643/return-to-azeroth-in-world-of-warcraft-forever) · [Questie's Forever manifest](https://github.com/Questie/Questie/blob/master/Questie_Forever.toc)

### Changes in 0.1.59

- **Almost done:** when all unfinished objectives have readable counters, at least 75% of counted progress is complete and only one to three units remain, FQN displays a subtle hint and the remaining enemy/item/task count. Attainable quests receive a small ranking bonus of 20–40 yards. Difficulty tiers and unknown-data handling remain in force. Drop chances and completion times are not inferred from counts.
- **Taxi travel view:** the actual taxi-flight state temporarily condenses the tracker, hides the rotating arrow and shows the selected quest's next step after landing. The selected target stays stable during the flight, except for deliberate overrides or an invalidated quest. Landing restores the chosen Compact/Detailed view and normal recommendations. This is a continuation hint, not a prediction of where the flight lands. Ordinary mounts and non-flight control loss do not activate the view.
- **Persistent notepad:** right-click an accepted quest or offer to remember it. `/fqn notes` or General settings opens the list. Entries have status, Map and Remove controls and are saved per character across reloads. Adding/removing notes does not pin, skip or otherwise change recommendation scores. Map uses a current known target when available, otherwise the saved position.
- **Keyboard bindings:** configure FQN's show/hide, active quest map and hold/release actions in WoW's AddOns key bindings. No keys are assigned automatically. The native `Bindings.xml` is included in release ZIPs without being treated as a TOC UI file.
- **Access search and filters:** search by quest, zone, saved name or ID; combine the search with All, In quest log or Completed. Filtering happens before pagination. Completed uses known turned-in flags; unknown/abandoned quests are not assumed complete.
- **Quick introduction:** three short pages explain the arrow, skip checkboxes and right-click menus. It appears once until dismissed or completed, waits until out of combat, and can be reopened from General settings or `/fqn help`.

### Changes in 0.1.58

- **Live session dashboard:** `/fqn session` displays six readable statistics and scrollable recent turn-ins. It updates once per second while visible. **Copy session summary** opens a separate selectable snapshot, so live updates cannot change text while copying it. `/fqn session reset` still starts a new session.
- **Saved access manager:** open **Saved access points** in General settings or `/fqn access`. All saved points are available, including those for completed quests. Entries show their quest, objective when known, zone and coordinates. Use Map, edit the name and Save, or Delete. Longer lists use pages of five; editing or deleting affects only the selected entry.
- **Compact/detailed tracker:** Appearance settings include a detail selector. Detailed is the default. Compact keeps quest titles, objectives, progress and navigation, while XP, zones and route text remain available in quest tooltips. Changing the view does not change recommendations, skips or manual selection.
- **Appearance preview and clearer settings:** the preview updates with text size and background opacity, without fading text. General settings expose session and access management; technical reports have their own Diagnostics section. Appearance reset also restores Detailed mode.
- **Validated packaging:** `scripts/package.py` builds a runtime-only ZIP from the TOC, follows XML file references, checks required files and prevents paths outside the addon. Text uses LF line endings and archive entries have stable timestamps. Version tags must match the TOC. The GitHub workflow tests Lua and packaging on main, pull requests, version tags and manual runs, then uploads the installable ZIP as a workflow artifact. ### Changes in 0.1.57

- **Return-aware recommendations:** when all unfinished goals and an outdoor finisher have usable positions, FQN estimates a nearest-next-goal route through up to ten goals and then to a known finisher. The score adds 35% of the further travel, capped at 1,000 yards, so distance, level suitability and follow-ups remain relevant. When comparing with known journeys, incomplete journeys receive a 200-yard uncertainty allowance. These allowances are ranking heuristics. Actual route totals in details are straight-line estimates, not terrain or completion-time estimates. Difficulty tiers still take precedence.
- **Access points:** right-click an accepted quest title in FQN. You can save your current outdoor position as that objective's access point, inspect available Questie extra-objective hints on the map, or explicitly adopt a hint as an access point. Hints are not automatically assumed to be entrances. Saved access points are per character and objective. FQN navigates to the point, then resumes the objective once within 12 yards. The menu can reuse or remove the point. An access point is ignored when the objective moves more than 300 yards from its saved reference. It supports one access point per objective, not a terrain navigation mesh. Known access points also contribute an exit leg to the unfinished quest's completion estimate. Turn-in navigation still targets the finisher; access/exit points remain inspectable in the route preview.
- **Session overview:** `/fqn session` or **Open session overview** in General settings opens a separate copyable snapshot of played time, observed XP, level gains, quest turn-ins, known turn-in XP and the last twenty turn-ins. Sessions are saved per character, survive reloads and logouts, and exclude offline time. `/fqn session reset` explicitly starts a new session. XP tracking runs even with the tracker hidden. A transition spanning several levels is labelled as a lower bound when intermediate XP thresholds are unavailable.
- **Target feedback:** right-click an active, alternative or offered quest and choose **Report an unsuitable target position**, or use `/fqn report` for the active quest. A separate editable report includes the selected quest ID, navigation and original objective positions, player position, and diagnostic context. Describe the issue, then copy it to a GitHub issue yourself. Nothing is sent automatically and FQN does not change Questie data.

## Controls and settings

- In the FQN settings, choose **Automatic (WoW language)**, **Deutsch**, or **English** under **Language**. The choice is saved account-wide. Use `/reload` to apply it.
- Settings are grouped under **General**, **Recommendations**, **Navigation**, and **Appearance**.
- **Show quest XP in the tracker** toggles the XP lines under the main quest and alternatives. It defaults to on and is saved account-wide. Route recommendations continue to use XP in either setting.
- **Text size** scales tracker and navigation text from 80% to 140%. **Visible accepted quests** and **Visible nearby offers** each allow two to five entries. Use the mouse wheel over either list or heading to scroll through additional quests. The headings show the visible range and total.
- Hover over the active quest title for **Why this quest?** and the current recommendation reasons. A gold **+** beside a quest title identifies an elite or group quest. Offer tooltips show the distance to the quest giver and then to the objective when both positions are known.

- Outside combat, click a quest's title in FQN to open WoW's quest details next to the map and mark its objective or turn-in. FQN uses its resolved target map even when the native details select a different region. If the native details are unavailable, the map still opens. [Forever quest details](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_UIPanels_Game/Mainline/QuestMapFrame.lua)
- Open an eligible quest in the WoW quest log and click **Set as active in FQN** beside **Back**. The action is also available in compatible right-click menus in the WoW quest log and Questie's active quest tracker. FQN ranks alternatives by distance from the active quest's known target and level fit. The arrows and displayed distances guide you from your current position. Use **Auto select** in FQN or **Resume FQN auto select** for the active quest to return to automatic recommendations. [Forever quest log](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_UIPanels_Game/Mainline/QuestMapFrame.lua)
- Click the checkbox before a quest name to skip it. A skipped quest stays in the game's quest log. If you skip the active quest, the tracker selects the next eligible one. An **Undo** button appears for eight visible seconds to restore the most recent skip.
- **Skipped (n)** appears when at least one accepted quest is skipped and opens the list, most recent first. Click a quest to restore it, or use **Restore all**. The list is saved per character and survives reload and logout. When a quest leaves the log, the tracker clears its skip. Manual selection resets at logout or UI reload.
- The distance after a quest name is the approximate straight-line distance in yards to the closest usable location, including on other zones in the same world space. It updates every second while the tracker is visible. `—` means the tracker has no usable distance. [Forever map API](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/MapDocumentation.lua)
- The main recommendation summarizes the available reasons under its objective, such as a nearby target, level fit, or a shared stop on a follow-up. Use **Map** on the active card to open its current destination. Expand **Route** for coordinates, walking or flight details, and the XP forecast. Alternatives retain their own route details. Opening a quest's map places a gold diamond at the same point used for its distance and arrow when coordinates are available. The marker follows changes to that quest's target and leaves WoW waypoints intact. Right-click the diamond to remove it. Opening an alternative's route or using its **Map** button keeps the active FQN recommendation.
- **Other targets nearby** lists accepted objectives and turn-ins within 500 yards of the main quest's target in the same zone. The distances in this list are measured from that target. Skipped quests and unfinished gray or red quests are omitted. Click an entry to open its map.
- **Outing order** in **Route details** plans up to three stops from accepted quests. FQN can include targets within 500 yards of the main objective or along its approach with up to 100 yards of estimated detour, even across a zone boundary. It promotes a closer first stop when reordering saves more than 120 yards of straight-line travel over starting at the main objective and visiting the same stops. After completing an objective or hand-in, FQN advances to the next stop. Manual selection and a recommended follow-up route take priority. The estimate ends at the final stop.
- Expand **Route** for **Next stops**, with the active stop highlighted and up to two following stops from the planned outing or known follow-up route. Each row shows its action, quest, and available straight-line distance. The first distance starts at the player, later distances start at the previous stop. Click a row to open its destination on the map.
- **On the way** lists up to three accepted objectives or turn-ins that are closer than the main destination and add no more than an estimated 100 yards each to the walking route. Click any stop to open its map position while keeping the active navigation target.
- For targets at least 1,500 yards away, **Route details** can recommend a flight. Open a flight master's map to record reachable routes from that departure point for your character. The comparison includes the approach to the flight master, the confirmed flight legs, and the final walk. Both walks must be within 1,000 yards and the estimated saving must be at least one minute. Times use straight-line walking distance and estimated flight time with an allowance for boarding and curves. A confirmed flight point near a target in another zone can still appear as a location hint. [Forever flight point API](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/TaxiMapDocumentation.lua) · [Forever flight map route rendering](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_FlightMap/FM_FlightPathDataProvider.lua)
- **Recommendations** combine distance and level fit. FQN uses red at +3 levels and above, orange at +1 to +2, yellow at −1 to 0, and green at −2 through the client's trivial-quest range. Below that range, quests are gray. Orange and green objectives get a distance penalty so a nearby quest can still beat a more distant yellow quest. Unfinished gray and red quests rank after regular objectives and are omitted from automatic outing and follow-up plans. Ready turn-ins are scored by distance. [Forever difficulty logic](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_FrameXMLUtil/Mainline/DifficultyUtil.lua)
- **Level-up forecast** shows the expected turn-in XP under the main recommendation and its alternatives when WoW reports a reward and active XP progress. Alternatives show a compact XP amount and a possible level-up. The XP remaining afterward appears in their route details. FQN can prioritize a ready turn-in within 100 yards of extra travel if it would make a nearby accepted quest change from red to orange or from orange to yellow. It recalculates based on the actual player level and quest rewards after leveling. The forecast uses one quest reward at a time. [Forever XP data](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/UnitDocumentation.lua)
- **Follow-up planning** runs with Questie and QuestieDB loaded. It compares visiting the first ranked target now with visiting it alongside a known follow-up stop after doing a different accepted quest. It considers up to two unambiguous follow-ups in the same world space, including delivery quests and simple kill quests. It changes the recommendation for shared stops within 40 yards when the estimated saving exceeds 40 yards plus any extra level penalty. Expand **Route details** for the proposed quest order, the shared visit and the straight-line estimates for both orders. A manual selection takes priority, and quest events trigger recalculation.
- **Show direction arrow** defaults to on. Each visible quest can show an arrow pointing toward the marker used for its distance. Arrows hide in instances, within three yards of their marker, or when usable coordinates or facing are unavailable. [Forever player API](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/PlayerScriptDocumentation.lua)
- **Show navigation at top of screen** is on by default. It shows the active quest arrow, title, and distance in a separate display. Drag it with the left mouse button to reposition it. Its background follows tracker opacity. Turn the option off to move the arrow back into the tracker.
- The arrow display briefly announces a changed quest, a new objective, or a quest becoming ready to turn in. Notices last four seconds.
- **Area overview** is a collapsible summary of accepted objectives and turn-ins with known positions in your current zone. Avoided objectives are omitted. Expand it to open a quest destination on the map. Use the mouse wheel to browse more than five entries.
- Navigation reports an unknown target position, arrival within three yards, unavailable character direction, or unavailable instance navigation. Messages appear in the separate display or in the active quest card.
- The **gear icon** opens the add-on options. `/fqn settings` opens the same page. **Tracker opacity** controls the window background and border from 0% to 100% and defaults to 80%. FQN saves the setting account-wide.
- Use **−** to show only the active quest and its details, and **+** to restore the lists. The accepted-quest and nearby-offer headings each show their quest count and can also be collapsed independently. FQN remembers all three states and keeps the top edge in place as the tracker grows or shrinks.
- **Allow changing window width** shows a resize grip in the lower-right corner. It is off by default. FQN saves the selected width account-wide and adjusts the height automatically.
- Use **Lock tracker position** and **Lock navigation position** to prevent accidental movement. Tracker locking also prevents resizing. **Reset window positions** restores both frames to their default locations.
- Outdoor elite quests are eligible and can be skipped individually. Tagged dungeon, raid and PvP objectives are filtered out of the recommendation and follow-up planning. A completed quest with a verified outdoor turn-in point remains eligible as a hand-in. [Forever quest tags](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/QuestLogDocumentation.lua)

### Optional Questie integration

- FQN refreshes the arrow and distance as objectives complete. FQN uses Questie coordinates for the closest unfinished item, object, event, or kill objective it can measure. **Questie kill locations** controls the use of kill coordinates and defaults to on. Blizzard's quest markers provide a fallback. When the quest is ready to turn in, FQN looks for a known outdoor turn-in location.
- FQN places the targeted objective and its distance first, followed by other open goals and a collapsible count of completed goals. Hover over a clipped quest title or objective to read its full text. The separate navigation display names that objective too. The automatic target stays selected until another goal is more than 25 yards closer or the current goal is completed. Click a goal with known coordinates to select it temporarily. Click it again or use **Back to automatic** to clear the selection.
- Right-click an objective with known coordinates to avoid it temporarily. Right-click again or use **Restore avoided objectives** on the card or under **Navigation** to allow it again. Avoidance clears on reload, objective completion, or quest removal. If every known objective is avoided, FQN reports that state and clears its target.
- **Questie nearby offers** defaults to on and shows nearby offers under **Available nearby** based on nearby NPC pins. The search radius applies to the quest giver and defaults to 350 yards, with a range of 50 to 1,000 yards. FQN considers level fit, the walk to the NPC and then to a known outdoor objective, proximity to the active target, and a small bonus for known XP. **Recommended** marks at most one offer, with a suitable quest level, a known short route and either a target near the active quest or a clear lead over other offers. Rows can show the target zone and expected XP, while the distance and arrow point to the NPC. Use **Show quest XP in the tracker** to toggle the XP text. FQN excludes accepted and completed quests. Questie may have incomplete prerequisite data for Forever, so confirm the offer with the NPC. [Questie's availability data issue](https://github.com/Questie/Questie/issues/7999)
- Click a nearby offer to open its quest giver on the map. Its tooltip shows the acceptance location, target zone, known XP, and the route reasons for a highlighted recommendation.

FQN uses Blizzard data when Questie is unavailable. FQN reads Questie's in-memory data. Questie and QuestieDB are distributed separately under their respective licenses. ## Compatibility research

- **Blizzard quest log.** Forever's generated API documents `C_QuestLog.GetNumQuestLogEntries`, `GetInfo`, `IsOnQuest`, `IsComplete`, `IsFailed`, `IsQuestDisabledForSession`, and `GetQuestObjectives`. The tracker uses the first `GetNumQuestLogEntries` return as the row count, skips headers, hidden and internal rows, and task rows, then confirms active membership with `IsOnQuest`. It uses the quest's reported `level`, which can reflect client scaling. Quest log, criteria, and watch updates trigger snapshots. `QUEST_REMOVED` supplies the quest ID used to clear a skip. Check enumeration with both open and collapsed quest headers in the live client. [Forever quest API and event definitions](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/QuestLogDocumentation.lua)
- **Questie.** The adapter was checked against the installed Forever package, Questie 12.9.0 with QuestieDB 1.1.1. It waits for `Questie.API.RegisterOnReady` and reads Questie's active quest and map structures. Those structures are internal and may change across Questie versions. [Questie Forever development notes](https://github.com/Questie/Questie/blob/master/docs/forever-development.md) · [Readiness API](https://github.com/Questie/Questie/blob/master/Public/RegisterOnReady.lua)
- **Map, tracking, and protected actions.** Forever's UI source exposes `C_Map.GetBestMapForUnit`, `GetPlayerMapPosition` with a nullable vector, `GetMapWorldSize` in yards, and `CanSetUserWaypointOnMap`. `C_QuestLog.GetNextWaypoint` may provide a native quest waypoint when available. Confirm outdoor, indoor, instance, and map-transition behavior before using these APIs for distance or positioning. Phase 1 reads quest state and does not change the native watch or supertrack state. Midnight's secret-value restrictions make live verification important for future combat-sensitive UI and navigation behavior. [Forever map API](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/MapDocumentation.lua) · [Blizzard's Midnight addon guidance](https://news.blizzard.com/en-us/article/24246290/combat-philosophy-and-addon-disarmament-in-midnight)
- **Taxi.** Forever exposes `C_TaxiMap.GetAllTaxiNodes` in the current flight-master context, `GetTaxiNodesForMap` for a map, and taxi-map events. A node listing is insufficient to infer travel connections or durations. Phase 4 needs live evidence for each character's unlocks, reachable routes, and reliable timing. Booking remains a manual player action. [Forever taxi API](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/TaxiMapDocumentation.lua)
- **Related work.** Guidelime demonstrates automatic guide progress updates. Shortest Path Forever provides an example of travel modeling, and Questie's bundled HereBeDragons includes Forever map-transform work. FQN derives its recommendation from the live quest log and ships no guide routes or bundled libraries in Phase 1. [Guidelime](https://github.com/max-ri/Guidelime) · [Shortest Path Forever](https://github.com/cjber/shortest-path-forever) · [Questie map compatibility notes](https://github.com/Questie/Questie/blob/master/docs/forever-development.md)

## Testing

Run `lua tests/run.lua` from the addon directory with Lua 5.1. The suite compiles the Lua files in manifest order and exercises the quest reader, ranking, skip and reset behavior, the elite and zone filters, objective selection, optional addon detection, and tracker event flow using mocked WoW APIs.

### In-game validation

1. Enter the world and run `/console scriptErrors 1` followed by `/reload`. Run `/dump GetBuildInfo()` and confirm that the fourth result is `16001`. Check that the tracker appears and `/fqn status` matches the addons actually loaded.
2. Accept two quests of different levels with markers in your current zone. Confirm the tracker recommends one even when neither is tracked by WoW. If the log offers collapsible sections, collapse and reopen a section containing the recommendation and check that it continues to appear.
3. Progress a multi-objective quest. Confirm open goals stay visible, the completed count can be expanded, and navigation advances to the next unfinished goal. Complete the quest, check **Ready to turn in**, and hand it in. Verify the recommendation advances. Also test abandoning the current recommendation and the empty-log state.
4. With at least four eligible quests, confirm the tracker shows three. Click an alternative name and verify that it opens the map while keeping the active recommendation. In the WoW quest log, right-click a quest and choose **Set as active in FQN**. Verify that it stays active after a log update, then click **Auto select**. Skip the active quest and an alternative, then run `/reload` and restart the game. Both entries should still be in **Skipped (n)**. Click one to restore it, then use **Restore all** to restore the rest.
5. Accept an outdoor elite quest and dungeon, raid and PvP quests. Verify only the outdoor elite is eligible. Complete a dungeon quest with an outdoor quest giver and verify its turn-in appears.
6. Move and close the tracker, then run `/reload`. Confirm it stays hidden until you type `/fqn` and reopens at the saved position. Repeat with Questie disabled, if installed, to verify standalone operation.
7. Click an active quest title and then an alternate quest in another zone. Verify WoW opens the correct map and highlights its native quest pin when present. The alternative must not replace the active recommendation. Hover both titles to check the explanation. Set a quest manually in the quest log and verify the tracker labels the override.
8. Walk toward a marked quest and confirm the displayed distance decreases. Open **Settings** from the tracker, adjust **Tracker opacity**, and confirm it stays set after `/reload`. Check that the version beside the title matches the manifest.

### Checking nearby quest offers

Blizzard's map reads `C_QuestLine.GetAvailableQuestLines` for quest offers and requests the data when the map opens. The list is a candidate source for a nearby-quest hint. Check it on Forever before relying on its coverage or treating a record as a quest your character can accept. The NPC dialogue provides the offers for the NPC you are currently visiting. Questie documents gaps in prerequisite data for Forever. [Blizzard map provider](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_SharedMapDataProviders/QuestOfferDataProvider.lua) · [Forever NPC dialogue API](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/GossipInfoDocumentation.lua) · [Questie's availability data issue](https://github.com/Questie/Questie/issues/7999)

1. In an outdoor zone, open the world map for your current zone. Run `/dump C_QuestLine.GetAvailableQuestLines(C_Map.GetBestMapForUnit("player"))` and note the quest IDs and names returned.
2. Visit a quest giver manually. Use `/dump C_GossipInfo.GetAvailableQuests()` while the dialogue with the quest list is open. If the game opens the details of a single offer directly, use `/dump GetQuestID()` in that dialog. Compare the offered ID with the map results before accepting anything.
3. Repeat with a quest you know requires an unfinished prerequisite and a non-repeatable quest you have already turned in. Compare their IDs with the map results. Record whether each appeared and whether the NPC offered it. If a known available quest is missing, note that as a coverage gap too.
