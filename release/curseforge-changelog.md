# Forever Quest Navigator 0.2.7

See the [0.2.7 release notes](curseforge-changelog-0.2.7.md): smooth in cities (planning in Undercity about 93 ms to 10 ms). Version 0.2.6: see the [0.2.6 release notes](curseforge-changelog-0.2.6.md): fix for the blocked-action message at login and skipping from the quest menu. Version 0.2.5: see the [0.2.5 release notes](curseforge-changelog-0.2.5.md): much smoother play (planning about 300 times faster, quest log updates about twice as fast). Version 0.2.4: see the [0.2.4 release notes](curseforge-changelog-0.2.4.md): fix for the blocked-action message and smoother play while the navigator is shown. Version 0.2.3: see the [0.2.3 release notes](curseforge-changelog-0.2.3.md): smarter recommendations (XP per minute, way to the turn-in, look-ahead, follow-ups, nearly finished quests, learned speed and preferences, explained in the tooltip) and target marks with /tm, click cycling and key bindings. Version 0.2.2 is documented in the [0.2.2 notes](curseforge-changelog-0.2.2.md): a Mark targets window for the active quest, real raid marks and nameplate marks with progress, loot reminder, respawn and danger hints, all open objectives, a quiet navigator in instances, hearthstone and turn-in hints, bag check, `/fqn time`, compact bar, quest sounds, per-character profiles and group sync on by default. Version 0.2.1 is documented in the [0.2.1 notes](curseforge-changelog-0.2.1.md).

Publication policy: regular Releases only. Alpha, beta and release-candidate uploads are disabled in the release pipeline. Older version-specific development notes remain as historical documentation.
