# Forever Quest Navigator 0.2.2

See the [0.2.2 release notes](curseforge-changelog-0.2.2.md): a Mark targets window for the active quest, real raid marks and nameplate marks with progress, loot reminder, respawn and danger hints, all open objectives, a quiet navigator in instances, hearthstone and turn-in hints, bag check, `/fqn time`, compact bar, quest sounds, per-character profiles and group sync on by default. Version 0.2.1 is documented in the [0.2.1 notes](curseforge-changelog-0.2.1.md).

Publication policy: regular Releases only. Alpha, beta and release-candidate uploads are disabled in the release pipeline. Older version-specific development notes remain as historical documentation.
