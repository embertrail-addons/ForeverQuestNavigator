Version 0.1.57 beta.

- Quest recommendations now consider further travel through known unfinished objectives and the return to an outdoor finisher, with bounded ranking allowances.
- Added per-objective access points: save your outdoor position or explicitly adopt an available Questie hint, navigate via the point, then continue to the objective.
- Added a separate persistent session overview with played time, observed XP, level gains and recent quest turn-ins. Open with /fqn session or from settings.
- Added editable, copyable target-position feedback from quest title context menus and /fqn report. Reports include the clicked quest and navigation/objective coordinates; nothing is sent automatically.
